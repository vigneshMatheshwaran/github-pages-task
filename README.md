\# GitHub Pages Static Website



\## Project Overview



A responsive personal portfolio website built using HTML and CSS and deployed using GitHub Pages.



\## Technologies Used



\* HTML5

\* CSS3

\* Git and GitHub

\* GitHub Pages



\## Deployment Steps



1\. Created an `index.html` file.

2\. Pushed the project to a GitHub repository.

3\. Enabled GitHub Pages in repository Settings.

4\. Selected the `main` branch and root folder.

5\. Verified the published website.



\## Learning Outcome



Learned how to deploy and update a static website using GitHub Pages at no hosting cost.
